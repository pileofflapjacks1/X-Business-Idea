# 🤖 Agent-in-a-Box

**Ready-to-use AI agents for everyday life — no coding needed.**

Pick an agent, give it a task, and watch it plan, search, and get things done for you.

---

## ⚡ 60-Second Quick Start

> **You'll be up and running in under a minute. Promise.**

**Step 1 — Get a free API key**
Go to [x.ai/api](https://x.ai/api) and sign up for free. Copy your API key.

**Step 2 — Paste your key**
In the left sidebar, find the "Get Started" box and paste your key there. It stays private in your browser only.

**Step 3 — Pick an agent**
Scroll down the sidebar and choose one of the four agents from the dropdown menu.

**Step 4 — Type a task**
In the chat box at the bottom of the page, type what you need help with (e.g. "Help me plan my week" or "Review my budget").

**Step 5 — Watch it work**
The agent will plan its approach, search the web if needed, and reply with a helpful answer. Done!

## 🛡️ Safety First

These agents come with built-in guardrails that are **on by default**:

- **Never spend money** — the agent will not make any purchases
- **Always ask before emails** — it will check with you first
- **Never share personal info** — your data stays with you
- **Budget limit** — you control how much API credit it can use per session

You can adjust all of these in the sidebar.

## ❓ Common Questions

**Do I need to know how to code?**
Nope! Just paste your API key and start chatting.

**Is my API key safe?**
Yes — it's stored only in your browser session and never sent anywhere except directly to x.ai.

**How much does it cost to use?**
The Grok API has a free tier. Each conversation uses a tiny amount of credit. The sidebar shows you exactly how much you've used.

**Can I change which agent I'm talking to?**
Yes — just pick a different one from the dropdown in the sidebar. Use "Clear Memory & Trace" if you want a fresh start.

**Something went wrong — what do I do?**
Try clicking "Clear Memory & Trace" in the sidebar and starting over. If the problem continues, make sure your API key is pasted correctly.
